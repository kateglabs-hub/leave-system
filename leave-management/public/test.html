Open your browser's developer console (F12 or Ctrl+Shift+J) and check for any error messages.

Common issues:

  • ❌ CORS errors - API not accessible from frontend
  • ❌ 404 errors - Files not found
  • ❌ 502 Bad Gateway - Backend not responding
  • ❌ Mixed content warning - HTTP/HTTPS mismatch
